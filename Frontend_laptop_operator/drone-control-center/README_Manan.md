# Drone Control Center File Guide

This file documents the files that are relevant to the project. Generated
dependencies, build output, caches, and temporary logs are intentionally not
listed as application source files.

## Project interfaces

The project has two separate browser interfaces:

1. `current_frontend/` - the restored standalone frontend.
2. `control_center/` - the active Drone Ground Station control-center frontend.

Both interfaces connect to the shared Python WebSocket backend in
`laptop_backend/`.

## Relevant files

### Project documentation

| File | Purpose |
|---|---|
| `README.md` | Main architecture, startup commands, ports, protocol notes, and bench-test guidance |

### Standalone frontend

| File | Purpose |
|---|---|
| `current_frontend/index.html` | Vite HTML entry point |
| `current_frontend/package.json` | Standalone frontend npm scripts and dependencies |
| `current_frontend/package-lock.json` | Locked standalone frontend npm dependency versions |
| `current_frontend/vite.config.js` | Standalone frontend Vite configuration; serves port `6970` |
| `current_frontend/src/main.jsx` | React application bootstrap |
| `current_frontend/src/App.jsx` | Standalone control UI, flight sliders, Pico outputs, telemetry, status, and event log |
| `current_frontend/src/styles.css` | Standalone frontend styling |

Start it from `current_frontend/`:

```powershell
npm install
npm run dev
```

Default URL: `http://127.0.0.1:6970`

### Drone Ground Station frontend

| File | Purpose |
|---|---|
| `control_center/index.html` | Vite HTML entry point |
| `control_center/package.json` | Ground Station npm scripts and dependencies |
| `control_center/vite.config.ts` | Ground Station Vite configuration; serves port `6969` |
| `control_center/src/main.tsx` | Ground Station React UI, WebSocket client, keyboard controls, telemetry, triggers, and trajectory state |
| `control_center/src/style.css` | Responsive 16:10 two-column layout and panel styling |

The Ground Station layout is:

- Top row: camera and IMU
- Middle row: 3D trajectory/telemetry and control log
- Bottom row: water contact and triggers
- Relative row proportions: `4:4:2`

Start it from `control_center/`:

```powershell
npm install
npm run dev
```

Default development URL when started this way:
`http://127.0.0.1:6969`

### Python backend and test tools

| File | Purpose |
|---|---|
| `laptop_backend/control_center_backend.py` | Shared WebSocket-to-UDP bridge; receives browser controls on port `5173`, forwards JSON control/trigger packets to the Raspberry Pi, and broadcasts Pi telemetry to browser clients |
| `laptop_backend/test_control_center_io.py` | Bench-test harness; sends control packets and synthetic telemetry, receives backend messages, and records JSONL logs |
| `laptop_backend/requirements.txt` | Python dependency list for the shared backend and test harness |
| `laptop_backend/.env.example` | Example network settings/reference values |

Run the backend from `laptop_backend/`:

```powershell
..\.venv\Scripts\python.exe control_center_backend.py --pi-ip 192.168.1.50
```

Run the test:

```powershell
..\.venv\Scripts\python.exe test_control_center_io.py `
  --ws-url ws://127.0.0.1:5173 `
  --duration 10 `
  --rate-hz 10 `
  --output .\control_center_io.jsonl
```

### Protocol responsibilities

| Link | Default | Responsibility |
|---|---:|---|
| Current frontend HTTP | `6970` | Serves `current_frontend/` |
| Control center HTTP | `6969` | Serves `control_center/` |
| Browser WebSocket | `5173` | Browser-to-backend control and backend-to-browser telemetry |
| Laptop-to-Pi UDP | `5000` | `CONTROL` and `TRIGGER` packets |
| Pi-to-laptop UDP | `5001` | `TELEMETRY` packets |

## Generated or redundant files

These files are not primary source files and can normally be regenerated or
removed after stopping the applications:

| Path | Recommendation | Reason |
|---|---|---|
| `current_frontend/node_modules/` | Remove/reinstall if needed | Installed npm dependencies; regenerated with `npm install` |
| `control_center/node_modules/` | Remove/reinstall if needed | Installed npm dependencies; regenerated with `npm install` |
| `.venv/` | Keep locally or recreate | Python virtual environment; not application source |
| `current_frontend/dist/` | Remove if desired | Vite production build output; regenerated by `npm run build` |
| `control_center/dist/` | Remove if desired | Vite production build output; regenerated by `npm run build` |
| `laptop_backend/__pycache__/` | Safe to remove | Python bytecode cache |
| `laptop_backend/control_center_io.jsonl` | Remove/archive after analysis | Generated test log, not source |

## Obsolete candidate

| File | Recommendation | Reason |
|---|---|---|
| `control_center/gaussian_video_server.py` | Keep | Synthetic video and water-signal producer used by the active control center |

Do not remove either obsolete candidate if an external camera/video test still
launches `gaussian_video_server.py`.

## Files that should not be manually edited

- `package-lock.json`: update it through npm.
- `dist/`: regenerate through the frontend build.
- `node_modules/`: regenerate through npm.
- `.venv/`: recreate through Python environment setup.
- `__pycache__/`: Python-generated cache.
